## Introdução a Data Analytics e Python
- Coleta, organização, análise, interpretação dos dados
- *perguntas chaves*: ==o que?; por que?; o que pode acontecer no futuro?; o que devemos fazer com base nesses dados?==
### Analise descritiva
- utiliza tabelas, gráficos, dashboards
- ==busca responder a pergunta *o que*==
-  *o dashboard não faz prescrição, quem faz é o leitor dos dados*
### Análise diagnóstica
- utiliza correlação e associação, análise exploratória de dados (AED), regressão
- ==busca responder a pergunta *por que*==
> uma mudança de paradigma pessoal, a regressão não é apenas preditiva, pode ser **diagnóstica**
### Análise preditiva
- utiliza regressão, árvore de decisão, redes neurais, ARIMA - em suma, modelos estatísticos e aprendizado de máquina (ML)
- ==busca responder a pergunta *o que vai acontecer*==
> existe uma diferenciação entre modelos estatísticos e ML, que justifique a inversão de preferência entre Python e R? Aparentemente ML depende de algoritmos que não envolvem variabilidade e distribuição de probabilidade, embora também trabalhe com amostras (não tenho ideia do que isso significa na prática).
### Aplicação
- ==prescrição (o que) atrelada a tomada de decisão (por que), com base na predição (o que vai acontecer)==
- examinar os dados para descobrir padrões, gerar insights baseados em evidência.
### Otimização
- focado na construção de indagações que busquem elucidar ==*o que fazer*==
- contextualizado com o apoio das análises - descritiva, diagnóstica e preditiva - para elaborar perguntas que busquem maximizar os resultados (lucro, reduzir custos, controlar estoque, etc.). Exemplo: *"qual preço maximiza o lucro?"*
